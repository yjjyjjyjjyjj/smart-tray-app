# 아마따 푸시 메시지 리스트

확인 기준: 2026-11-01, 현재 Android 앱 소스 코드.

앱이 생성하는 Android 시스템 알림의 실제 제목·본문과 발송 조건을 정리합니다. 서버에서 보내는 원격 푸시가 아니라 Kotlin에서 생성하는 로컬 시스템 알림입니다. `{…}`는 설정이나 상태에 따라 바뀌는 값입니다.

**현재 구현 상태:** 실제 펌웨어의 상태 디코더와 Kotlin 알림 정책을 연결했습니다. 유효한 상태로 문 열림·미수거·우산·문 열림 유지 알림을 판단하며, 실제 센서·시스템 알림의 통합 시험 결과는 별도 기록합니다.

## 1. 외출 안내 알림

알림 채널은 **외출 전 확인**(`tray_reminders`)입니다. Android 알림 권한과 해당 채널이 허용되어 있어야 하며, 자동 발송에는 앱의 **전체 알림**과 해당 기능 설정도 켜져 있어야 합니다.

| 번호 | 구분 / 내부 종류 | 제목 | 본문 |
| --- | --- | --- | --- |
| 1 | 소지품 미수거 / `belongings` | 잠깐, 두고 간 물건이 있어요 | {트레이명 목록}에 물건이 남아있어요. 외출 전에 확인해주세요. |
| 2 | 현관문 열림 / `door` | 현관문이 열렸어요 | 트레이 상태를 확인하고 외출을 준비하세요. |
| 3 | 비 예보 우산 안내 / `umbrella` | 오늘은 우산도 챙겨요 | 오늘 {비 오는 시간대} 비 예보가 있어요. 우산 공간에 있는 접이식 우산을 챙겨 주세요. |
| 4 | 문 열림 유지 — 최신 열림 확인 / `door-left-open` | 현관문이 계속 열려 있어요 | 현관문이 {N}초 이상 열려 있어요. 문이 잘 닫혔는지 확인해 주세요. |
| 5 | 문 열림 유지 — 닫힘 확인 불가 / `door-left-open` | 현관문이 닫혔는지 확인해 주세요 | 문이 열린 뒤 {N}초 동안 닫힘 신호를 받지 못했어요. 외출하셨다면 현관문을 확인해 주세요. |

### 1-1. 소지품 미수거

- **발송:** 문이 닫힘 → 열림으로 바뀌고, 소지품 미수거 알림이 켜져 있으며, 알림이 켜진 1·2번 트레이 중 정상 센서가 물건 있음을 나타내는 칸이 있을 때.
- **묶음 처리:** 남아 있는 대상 트레이를 하나의 알림으로 합칩니다. 개별 알림이 꺼진 칸과 센서 오류·수신 대기 칸은 제외합니다. 우산 공간은 별도 우산 알림으로 처리합니다.
- **이름 표시:** 사용자 별칭을 사용하고, 별칭이 `트레이`로 끝나지 않으면 뒤에 ` 트레이`를 붙입니다. 여러 이름은 `, `로 연결합니다.
- **본문 예시:** `1번 트레이, 출근 준비 트레이에 물건이 남아있어요. 외출 전에 확인해주세요.`
- **알림 버튼:** `트레이 확인`.
- **누르면 이동:** 대상이 한 칸이면 해당 트레이 상세, 두 칸이면 트레이 목록.

### 1-2. 현관문 열림

- **발송:** 문이 닫힘 → 열림으로 바뀌고 현관문 열림 알림이 켜져 있으며, 같은 이벤트에서 위 소지품 미수거 알림이 생성되지 않았을 때.
- **우선순위:** 소지품 미수거 알림과 현관문 열림 알림은 같은 이벤트에서 둘 다 보내지 않습니다. 소지품 미수거가 우선입니다. 미수거 알림을 껐거나 대상 트레이가 없으면 현관문 열림 알림을 보낼 수 있습니다.
- **알림 버튼:** `홈에서 확인`.
- **누르면 이동:** 홈.

### 1-3. 비 예보 우산 안내

- **발송:** 문이 닫힘 → 열림으로 바뀔 때, 우산 알림이 켜져 있고 정상·최신 적외선 센서가 우산 있음을 나타내며, 유효한 오늘 남은 시간의 비 예보가 있을 때.
- **예보:** 기상청의 비·비/눈·소나기를 대상으로 합니다. 눈만 오는 예보는 대상이 아닙니다. 위치 권한, 정상 조회 상태와 유효한 예보가 필요합니다.
- **시간대 표시:** 이어지는 비 예보 구간은 합칩니다. 예: `10:00~12:00, 16:00~17:00`.
- **본문 예시:** `오늘 10:00~12:00, 16:00~17:00 비 예보가 있어요. 우산 공간에 있는 접이식 우산을 챙겨 주세요.`
- **발송하지 않음:** 비 예보 없음, 우산 없음, 센서 오류·수신 대기, 오래된 센서값·예보, 예보 확인 실패. 우산을 꽂거나 꺼냈다는 이유만으로도 보내지 않습니다.
- **중복 방지:** 같은 문 열림에서는 한 번만 보냅니다. 문이 열린 상태에서 요청한 예보가 도착하면 조건을 다시 판단할 수 있습니다. 소지품 미수거·현관문 열림 안내와는 별도로 발송할 수 있습니다.
- **알림 버튼:** `우산과 날씨 확인`.
- **누르면 이동:** 우산과 날씨 화면.

### 1-4. 문 열림 유지 — 두 문구 중 하나

- **시간 설정:** `{N}`은 사용자가 지정한 문 열림 판단 시간입니다. 현재 코드 기준 **10~300초**, 기본값 **30초**입니다.
- **발송:** 유효한 문 열림을 확인한 뒤 N초가 지날 때까지 닫힘을 확인하지 못했고, 문 열림 유지 알림이 켜져 있을 때.
- **4번 문구:** 알림 시점에도 연결되어 있고, 최근 45초 이내의 센서값이 문 열림을 나타낼 때.
- **5번 문구:** 열림을 확인한 뒤 연결이 끊기거나 센서값이 오래되어 현재 닫힘 여부를 확인할 수 없을 때. 연결 끊김 자체를 문 열림이나 외출로 단정하지 않습니다.
- **공통:** 한 번의 열림에서는 두 문구 중 하나만 한 번 보냅니다. 유효한 닫힘을 받으면 대기를 취소합니다. 연결 유실·재연결·시간 설정 변경으로 처음 열린 시각을 초기화하지 않습니다.
- **시작 기준:** 열림 신호를 한 번도 받지 않았다면 시작하지 않습니다. 최초 연결에서 유효한 열림을 받으면 대기는 시작할 수 있습니다. 이는 닫힘 → 열림 전환이 필요한 1·2·3번과 다릅니다.
- **종료·제한:** 사용자가 연결을 해제하거나 서비스를 중지하면 대기도 종료합니다. 대기 상태는 프로세스 종료·재부팅 뒤 복원하지 않습니다.
- **알림 버튼:** `홈에서 확인`.
- **누르면 이동:** 홈.

1·2·3번은 최초 연결·재연결에서 처음 받은 문 상태를 기준값으로 사용하고, 이후 닫힘 → 열림 전환에서 판단합니다. 같은 열림 상태의 반복 수신은 새 열림 이벤트로 처리하지 않습니다. 각 알림의 잠금화면·팝업 표시 여부는 휴대폰과 알림 채널 설정에 따릅니다.

| 내부 종류 | `preview` |

## 3. Bluetooth 연결 유지 알림

백그라운드 통신 서비스의 실행 상태를 표시하는 상주 알림입니다. 외출 안내 알림과 구분됩니다.

- **공통 제목:** `아마따 연결`.
- **채널:** `트레이 연결`(`tray_connection`, 기본 중요도 낮음).
- **본문 누르기:** 홈으로 이동.
- **동작 버튼:** `연결 해제` — 통신 서비스와 진행 중인 문 닫힘 확인 대기를 종료.
- **표시 방식:** 같은 알림 ID를 갱신하며, 상태가 바뀔 때마다 새 외출 알림으로 쌓지 않습니다.

| 상태 | 본문 | 현재 사용 여부 |
| --- | --- | --- |
| 연결 준비 | HC-06 연결을 준비하고 있어요 | 사용 |
| 시스템 페어링 대기 | HC-06 시스템 페어링 확인 대기 | 사용 |
| 최초 소켓 연결 시도 | HC-06 RFCOMM 연결 중 | 사용 |
| 연결 성공·상태 재조회 | HC-06 연결됨 · 센서 수신 대기 | 첫 유효 상태 수신 전 |
| 유효 센서 상태 수신 | HC-06 연결됨 · 센서 수신 중 | 상태 검증 통과 뒤 |
| 재연결 대기 | HC-06 재연결 대기 · {회차}회차 | 사용 |
| 재연결 시도 | HC-06 재연결 중 · {회차}회차 | 사용 |
| 연결 복구 종료 후 남은 문 확인 대기 | 현관문 닫힘 확인 대기 · Bluetooth 연결 끊김 | Bluetooth 꺼짐·권한 문제 등으로 재연결을 끝내지만 기존 문 닫힘 확인을 잠시 유지할 때 |

현재 연결 유지 알림의 모듈 이름은 코드에 `HC-06`으로 고정되어 있습니다. 장치의 실제 표시 이름이 `AMATTA`여도 위 문구를 사용합니다.

## 4. 별도의 시스템 알림을 보내지 않는 항목

- 트레이에 물건을 놓거나 가져가는 동작 자체: 활동 기록으로 남기며, 해당 동작만으로 푸시를 보내지 않습니다.
- 현관문 닫힘 자체: 활동 기록과 상태 표시 대상입니다.
- 우산 거치·제거, 비 예보 없음, 맑음·흐림·눈 상태 자체.
- LED 점등·소등, 살균 시작·종료, 팬 동작·종료.
- 위치·날씨 조회 실패, Bluetooth 검색·권한 오류 등의 앱 화면 안내와 토스트. Bluetooth 연결 상태는 위 상주 알림을 갱신할 수 있지만, 별도의 오류 푸시는 만들지 않습니다.
